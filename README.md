# Maintenance Breakdown & MTTR Tracker

Machine-breakdown logging and MTTR (Mean Time To Repair) tracking web app, replacing manual breakdown logs with automated plant-wide reporting.

## Tech Stack
`Node.js` `Express.js` `Cloudflare Tunnel` `Claude AI`

## Highlights
- Digital logging of machine breakdowns as they happen, replacing paper/manual logs
- Automated MTTR (Mean Time To Repair) and MTBF (Mean Time Between Failures) reporting
- Plant-wide visibility into equipment reliability trends
- Deployed securely via Cloudflare Tunnel

## Why I Built This
Breakdown records were scattered across manual logs with no reliable MTTR/MTBF metrics. This app centralizes breakdown data and auto-generates the reliability metrics maintenance teams need.
